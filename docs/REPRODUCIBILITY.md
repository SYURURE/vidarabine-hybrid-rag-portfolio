# Reproducibility

## 再現レベル

| レベル | この公開版で可能か | 内容 |
|---|---|---|
| パッケージ整合性 | 可能 | manifest、構文、JSON、秘密情報パターンを検査 |
| 合成検索デモ | 可能 | 同梱データで検索・根拠不足ゲートを再実行 |
| 合成評価 | 可能 | 5問の期待根拠IDを再評価 |
| Ollama接続 | 条件付き | 利用者がOllamaと指定モデルを準備した場合 |
| 元実習のビダラビン検索品質 | 不可 | 第三者資料由来コーパスを公開していないため |
| 医学的妥当性 | 対象外 | 本成果物は医療検証ではないため |

## 標準検証

```powershell
python .\scripts\verify_portfolio.py
```

このスクリプトは、配布物の構造、Python構文、JSON/JSONL、禁止拡張子、秘密情報・個人PCパスの一般的パターン、単体テスト、合成評価、`MANIFEST.sha256` を確認します。

`data/private`はローカル入力なのでmanifestと公開検査の対象外です。公開ZIPは `scripts/build_public_zip.ps1` がmanifest記載ファイルだけを集めて作成します。

## 期待結果

```text
VERIFY PASSED
```

単体テストは5件、合成評価は5件です。単体テストには旧キーワード文書形式の互換変換も含まれます。GitHub Actionsも同じ検証スクリプトを実行します。

## 決定性

既定の `portable` 検索はPython標準ライブラリだけを使い、同一ファイルに対して決定的です。Ollama埋め込みまたは回答生成を有効にすると、モデル版、推論環境、生成の非決定性が加わります。

## 検査が保証しないこと

- 実際の医薬品情報の正確性・完全性・最新性
- 非公開コーパスの内容や変換過程
- 医療安全、規制適合、品質保証、第三者監査
- あらゆる秘密情報・著作物の完全検出
- 未知の質問に対する一般化性能

GitHub Actionsの緑のチェックは、指定された自動検査が通ったことを示すだけで、医学的承認や第三者認証ではありません。
